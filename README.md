# Inventory Management System

A console-based Java application developed as an academic project for the Data Structures course. The system manages product and inventory information while applying object-oriented programming concepts and Java data structures.

## Features

* Add and manage product information
* Track product names, prices, quantities, costs, and sales
* Organize inventory data using Java collections
* Perform inventory operations through a console-based interface

## Technologies and Concepts

* Java
* Data Structures
* ArrayList
* HashMap
* Object-Oriented Programming (OOP)
* Eclipse IDE

## Project Structure

* `Inventory.java` – Contains the main inventory logic and product management operations
* `module-info.java` – Defines the Java module

## Learning Outcomes

Through this project, I practiced organizing data using Java collections, designing classes and objects, and implementing inventory operations in a structured console-based application.
